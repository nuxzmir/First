Очки реальности - полностью блокируют ИИшные идеи, заставляя тебя думать самому. Они только поддерживают твои идеи, но не способны развивать их самостоятельно. Также он имеет наказание при засечении использования ИИ, он заставляет тебя решить полностью случайную задачу не зависимо от предмета или сложности, предоставляя только базовый справочник.Еще он может помогать в решениях (по типу играть в игры или читать) определяя что будет для тебя полезнее и убеждая тебя в этом, развивая префронтальную кору
